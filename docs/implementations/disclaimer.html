Disclaimer

Information on this page is submitted by providers and others. W3C does not endorse specific products. The UCM Community Group does not endorse specific products.

What a listing means

An implementation is listed because, when it was submitted, its entry met the listing criteria: a public project URL, a public run of the group's test fixtures, a profile the group defines, a license and a reported-on date. Nothing more is implied.

What a listing does not mean

  • Neither W3C nor the UCM Community Group has reviewed an implementation's quality, security, privacy, accessibility or fitness for any use, including care delivery.
  • No listing is a certification, a statement of conformance or an endorsement. Neither W3C nor the Community Group runs a certification program for the Unified Care Model.
  • Entries are listed alphabetically by name. The order is not a ranking, and the page carries no ratings.

Reported results

Test results are reported by the people who submit them, as of the reported-on date. The specification and the implementations both change, so a result may not describe the current version of either. Follow the test run link to see exactly what was run.

No commercial information

The Community Group is not a commercial venture. Listings carry no pricing, support or sales contact information, and the group does not arrange engagements with the people or organizations behind an implementation.

Synthetic data only

Test runs and examples linked from this page must use synthetic data. They must never contain real personal or health information. Report any that do to the chairs, and the entry will be removed.

Corrections and removal

To correct or remove an entry, open an issue or pull request in the group's repository, or write to the group's public mailing list. The chairs may remove an entry that no longer meets the listing criteria, for example when one of its links no longer resolves.

About the specification

The Unified Care Model is developed by the W3C Unified Care Model Community Group. It is not a W3C Standard and is not on the W3C Standards Track.
