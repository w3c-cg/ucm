Submitting an implementation

Open a pull request that adds one entry to docs/implementations/entries.yaml. An entry is listed when it meets these criteria:

Public project
A public https URL for the project or its repository.
Public test run
A public https URL of a run of the group's test fixtures against the implementation.
Profile
One of the profiles listed below.
License
An SPDX license identifier or expression.
Reported on
The date the results were reported.

Continuous integration checks each entry against these criteria and checks that its links resolve. The chairs own this page and review every submission; a reviewer does not review a submission they are involved in.

Entries carry no rankings or quality ratings, no language implying certification, standardization or endorsement, and no commercial support, pricing or contact links. Test runs must use synthetic data only.
